## 0.18.13 / plugin 0.2.7 发布说明

本版本集中解决了论文复现工作区在 DSH 侧栏的层级收纳、远程执行目标架构重构、内嵌 WebView 外链跳转以及公网移动端访问等一系列高频核心痛点。

---

### 1. 自动补全缺失的祖先集合工作区（修论文裸露脱壳）

- **痛点**：用户在 Zotero 里新建了集合分类（如 `3dworldmodel`）或移动文献后，若未手动跑集合全量同步便直接对论文点击「打开会话」或「为这篇论文建工作区」，由于父集合并未在 DSH 中注册为工作区，DSH 侧栏在计算目录树折叠时找不到直接父工作区，便一路向上退避挂在「Zotero 集合」最外层根目录下，导致论文脱壳裸露。
- **修复**：
  - 增加 `ensureAncestorCollectionWorkspaces`：在每次创建或打开论文会话前，自动探测自集合根到论文父目录之间的所有祖先集合目录；
  - 若有未在 DSH 注册的集合目录，立即自动将其注册为折叠工作区，并同步其对应的 Zotero 集合真实名称；
  - 无论用户层级多深，论文均能准确收纳在所属分类的子层级中。

### 2. 论文工作区标题脱敏去重

- 优化 `workspaceTitle` 生成规则：移除默认落点下强行追加末段目录名的逻辑，杜绝产生如「`论文标题 · 论文标题前70字`」的重复拼接，保持侧栏与工作区卡片整洁美观。

### 3. 远程执行目标架构重构（无侵入工作区注入）

- 摒弃以往在本地凭空新建锚点目录和工作区的沉重做法，将远程算力目标（SSH 别名与远程路径）定义为已有工作区的一项环境属性。
- 采用无侵入的 `AGENTS.local.md` 工作区指令文件机制：DSH 的 `dsh-agent-instructions` 会自动沿工作区层级加载该文件，向该工作区下的**每一个对话会话**自动注入远端执行指引（如 `ssh lab-gpu`、远端工作路径、tmux 会话保活等），左侧栏零新增。

### 4. 两段式安全配置工具（Preview & Apply）

- 为 Agent 提供了安全的对话式远程目标配置接口：
  - `zotero_workspace_remote_preview`：只读生成将要写入的内容与一次性 `planId`；
  - `zotero_workspace_remote_apply`：必须凭借 5 分钟有效且用掉即作废的 `planId` 方可落地执行；
  - 从状态机底层强制要求模型必须先向用户展示配置内容并取得明确确认后方可修改。

### 5. 内嵌 WebView 链接点击跳转与上下文菜单

- 解决 Zotero 内嵌 DSH 面板中 Markdown 外部链接被沙箱拦截无法点击跳转或复制的问题。
- 增加 `/open-external` 服务端路由，点击外链直接唤起系统默认浏览器；
- 增加右键菜单：支持「在浏览器中打开」、「复制链接地址」、「复制文字」，并具备坐标兜底与 Toast 反馈。

### 6. 18100 公网直连与移动端网络穿透

- 针对国内移动网络访问 Cloudflare 免费版跨境绕行（700~1700ms）的问题，打通 18100 高位直连通道（延迟骤降至 16ms 级）；
- 在反代中补全 `Host`、`Origin`、`Referer` 改写，顺利通过 DSH browser-trust fence；
- 为 60+ 模块超大 JS bundle 开启专用缓冲与 `dsh_cache` 缓存，解决移动网络断流导致的 "Failed to load plugins" 报错；
- 增加 GeoIP 深圳与显式 IP 组合白名单，抵御公网扫描。
